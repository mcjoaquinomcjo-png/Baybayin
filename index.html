1. About Baybayin

Origins, historical lineage, and cultural resurgence

Baybayin (from the Tagalog root word baybay, meaning "to spell" or "to trace along a coast") is an ancient pre-colonial Philippine writing system belonging to the Brahmic family of scripts. Extensively used in Luzon and the Visayas prior to Spanish colonization, Baybayin is an abugida, wherein each consonant character possesses an inherent vowel sound.

ᜊ
Base Syllable (No Mark)
Default inherent vowel ends in /a/ (e.g., ᜊ = BA).
ᜊᜒ
Kudlit Above (◌ᜒ)
Changes the vowel to /i/ or /e/ (e.g., ᜊᜒ = BI / BE).
ᜊᜓ
Kudlit Below (◌ᜓ)
Changes the vowel to /o/ or /u/ (e.g., ᜊᜓ = BO / BU).
ᜊ᜔
Pamudpud / Virama (◌᜔)
Mutes the vowel entirely, leaving the standalone consonant (e.g., ᜊ᜔ = B).

3 Essential Writing Rules

Core linguistic principles for writing accurately in Baybayin

Rule 01
Write by Sound, Not Latin Letters
Always spell words phonetically based on spoken Tagalog syllables. Foreign sounds like F, V, and C map to their nearest native equivalents (P, B, KA/SA).
"Coffee" ➔ Kape ᜃᜉᜒ
Rule 02
The "NG" Principle
In Baybayin, NG is a single native consonant (ᜅ), not two separate letters (N + G). Never combine N and G.
"Hangin" ➔ HA - NGI - N ᜑᜅᜒᜈ᜔
Rule 03
Consonant Clusters & Loanwords
Classical Baybayin did not accommodate consecutive consonants (e.g. PR, ST). In modern practice, consonants in a cluster use a pamudpud, or use pure Tagalog terms.
"Lalawigan" (Province) ᜎᜎᜏᜒᜄᜈ᜔
