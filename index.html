1. About Baybayin

Baybayin (from the Tagalog root word baybay, meaning "to spell" or "to trace a coast") is an ancient pre-colonial Philippine writing system belonging to the Brahmic family of scripts.

2. Mechanics & Vowel Modifiers

Every base consonant character naturally carries an inherent "A" vowel sound. Diacritic marks called Kudlit alter or cancel this vowel sound:

Diacritic / Mark Name Function Example Pattern
(No mark) Base Syllable Default sound ends in /a/ ᜊ = BA
Dot Above ◌ᜒ Kudlit (I / E) Changes vowel to /i/ or /e/ ᜊᜒ = BI / BE
Dot Below ◌ᜓ Kudlit (O / U) Changes vowel to /o/ or /u/ ᜊᜓ = BO / BU
Cross Below ◌᜔ Pamudpud / Virama Cancels the vowel (isolates consonant) ᜊ᜔ = B

3. Essential Writing Patterns & Rules

Pattern 1: Write by Sound, Not Latin Spelling

Always spell words phonetically based on spoken Tagalog syllables rather than English letters. Foreign sounds like F, V, and C are mapped to their nearest native equivalents (P, B, KA/SA).

Example: "Coffee" ➔ Kape ➔ ᜃᜉᜒ (KA - PE)

Pattern 2: The "NG" Principle

In Baybayin, NG is a single native consonant character (ᜅ), not two separate letters (N + G). Combining N + G is incorrect.

Example: Hangin (Wind) ➔ HA - NGI - N ➔ ᜑᜅᜒᜈ᜔

Pattern 3: Consonant Clusters & Foreign Loanwords

Traditional Baybayin did not support consecutive consonants (like PR or ST). In modern usage, each consonant in a cluster is muted using a pamudpud, or translated using pure Tagalog words.

Example: Lalawigan (Province) ➔ ᜎᜎᜏᜒᜄᜈ᜔ (Preferred over foreign loanword Probinsya)
