# ᜊᜌ᜔ᜊᜌᜒᜈ᜔ · Baybayin Master Portal

A modern, clean, and minimalistic web portal for learning, transliterating, and mastering **Baybayin** — the ancient pre-colonial Philippine script.

🌐 **Live Web Host**: [https://mcjoaquinomcjo-png.github.io/Baybayin/](https://mcjoaquinomcjo-png.github.io/Baybayin/)

---

## ✨ Features

1. **Learn & Mechanics**:
   - Historical background and Brahmic lineage of Baybayin.
   - **Interactive Kudlit Live Studio**: Real-time syllable builder with diacritic modifiers (`-A`, `-I/-E`, `-O/-U`, `Virama`) and native audio pronunciation.
   - 3 Essential writing rules: Sound over Latin spelling, the *NG* principle, and loanwords/consonant clusters.
   - Character reference chart for standalone vowels and consonants.

2. **Translator & Keyboard**:
   - **Real-Time Latin ⇄ Baybayin Converter**: Live phonetic transliteration with one-click copy and audio reader.
   - Tactile Virtual Keyboard for manual character-by-character composing.
   - **15 Classical Vocabulary Flashcards** (*Bayanihan*, *Pakikipagkapwa*, *Pinaglikhaan*, etc.) with live search and native pronunciation audio.

3. **Assessment Hub (10 Mastery Levels)**:
   - Progressive 10-level quiz system (50 questions).
   - LocalStorage score persistence so you never lose your progress on reload.
   - Grand Celebration modal with interactive canvas particle fireworks upon achieving 10/10 level mastery.

4. **Classic Stories & Epics Reader**:
   - 11 traditional Philippine folktales and epics (including the full epic of *Biag ni Lam-ang*).
   - Side-by-side / parallel Baybayin & Tagalog text with toggleable translation and customizable text size.

## 🚀 How to Host & Run

### Option 1: GitHub Pages (Free Live Hosting)
1. Go to your repository settings on GitHub: **Settings > Pages**.
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your website will be live in ~1-2 minutes at:
   `https://mcjoaquinomcjo-png.github.io/Baybayin/`

### Option 2: Google Apps Script Web App
1. Open [Google Apps Script](https://script.google.com/).
2. Create a new project and paste `Code.gs` into the script editor.
3. Add an HTML file named `Index` and paste the contents of `index.html`.
4. Click **Deploy > New deployment > Web app** (Access: Anyone).

### Option 3: Local Preview
Simply open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox).
